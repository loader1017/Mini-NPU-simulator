# Mini-NPU-simulator

## 1. 프로젝트 소개

본 프로젝트는 AI 연산의 핵심인 MAC(Multiply-Accumulate) 연산을 이해하고, 이를 통해 입력된 패턴이 'Cross(+)'인지 'X'인지 판별하는 시뮬레이터입니다. 외부 라이브러리(NumPy 등)를 배제하고 순수 Python의 반복문만을 사용하여 NPU의 연산 원리를 재현했습니다.
## 2. 핵심 구현 사항

    MAC 연산 엔진: 2차원 배열을 순회하며 원소별 곱셈과 전체 누적합을 구하는 로직을 직접 구현했습니다.

    부동소수점 오차 관리: 연산 결과 비교 시 정밀도 문제를 해결하기 위해 허용 오차(1e-9) 정책을 적용하여 판정의 신뢰도를 높였습니다.

    라벨 정규화: +, cross, x 등 다양한 형태의 입력 라벨을 내부 표준(Cross, X)으로 통일하여 비교 로직의 일관성을 유지했습니다.

    동점 판정 로직: 두 필터와의 유사도 차이가 오차 범위 내일 경우 UNDECIDED를 반환하여 엄격한 판정을 수행합니다.

## 3. 시간 복잡도 분석 (O(N2))

본 시뮬레이터의 연산 효율성은 입력 데이터의 크기 N에 대해 **O(N2)**의 시간 복잡도를 가집니다.
분석 근거

    중첩 반복문: calculate_mac 함수는 N×N 행렬의 모든 원소를 한 번씩 방문해야 하므로 N×N=N2번의 곱셈 및 덧셈 연산이 발생합니다.

    실측 데이터:
    크기 (N×N)	연산 횟수 (N2)	측정 평균 시간 (ms)
    3 x 3	9	0.001 ms 미만
    5 x 5	25	0.002 ms 내외
    13 x 13	169	0.015 ms 내외
    25 x 25	625	0.050 ms 내외
    (실제 측정값은 PC 환경에 따라 다를 수 있으나, N2이 커짐에 따라 시간이 비례하여 증가함을 확인했습니다.)		

## 4. 실패 케이스 분석 (Troubleshooting)

분석 과정에서 발생한 주요 실패 원인과 해결 방안입니다.

    수치적 동점: 패턴 내의 모든 값이 동일할 경우 두 필터와의 점수가 같아져 UNDECIDED가 발생합니다. 이는 알고리즘의 한계가 아닌, 데이터의 중립성을 정확히 판정한 결과입니다.

    데이터 스키마 오류: data.json의 키(size)와 실제 배열의 크기가 일치하지 않을 경우 ValueError를 발생시키고 예외 처리를 통해 프로그램의 안정성을 확보했습니다.
